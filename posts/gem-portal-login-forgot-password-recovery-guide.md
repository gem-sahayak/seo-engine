# GeM Portal Login & Password Recovery Guide 2026: Reset User ID & Password

Government e-Marketplace (GeM) portal par login karte waqt password bhool jaana, OTP na aana, ya Primary User ID lock ho jaana MSME sellers aur government buyers ke liye sabse common problem hai. 

Is comprehensive guide mein hum step-by-step samjhenge ki **GeM login password reset kaise karein**, **forgot User ID ko kaise recover karein**, aur **mobile OTP issues ko kaise fix karein**.

---

## 🔑 Summary Checklist for GeM Login Recovery

| Issue | Solution | Recovery Time |
|---|---|---|
| **Forgot Password** | Click 'Forgot Password' -> Enter User ID -> Verify Mobile/Email OTP | 2 Minutes |
| **Forgot User ID** | Click 'Forgot User ID' -> Enter Registered GSTIN / Aadhaar -> Verify OTP | 5 Minutes |
| **Account Locked (3 Bad Attempts)** | Wait 30 minutes for auto-unlock or use 'Forgot Password' link | 30 Mins / Instant |
| **OTP Not Received** | Check DND status on mobile or switch to registered Email OTP | 2 Minutes |
| **Primary User Changed** | Initiate 'Transfer Primary User' request with organization authorization letter | 24–48 Hours |

## Step 1: GeM Portal Login Password Reset Process

Agar aap apna GeM portal password bhool gaye hain, toh neeche diye gaye steps follow karein:

1. Official GeM Portal login page (`https://gem.gov.in`) par jayein aur **Login** button par click karein.
2. Login screen par **Forgot your Password?** link par click karein.
3. Apna **User ID** enter karein (User ID case-sensitive hoti hai).
4. Screen par dikhaya gaya Captcha code sahi enter karein aur **Submit** button dabayein.
5. Aapke registered mobile number aur email ID par 6-digit OTP bheja jayega.
6. OTP verify karne ke baad, ek naya strong password create karein (minimum 8 characters, at least 1 uppercase letter, 1 number, and 1 special character like `@`, `#`, `$`).
7. New password save karne ke baad dobara login karein.

---

## 🆔 Step 2: Forgotten GeM User ID Recovery

Agar aap apna **User ID** bhool gaye hain:

1. GeM login screen par **Forgot User ID** link par click karein.
2. Select karein ki aap **Seller** hain ya **Buyer**.
3. Apna registered **GSTIN** (General Sellers for Goods) ya **PAN / Aadhaar Number** (Proprietorships / Individuals) enter karein.
4. Registered mobile number par received OTP enter karke verify karein.
5. System aapke screen par aapka masked User ID dikhayega aur complete User ID aapke registered email ID par mail kar dega.

## 📱 Mobile OTP Delays & DND Troubleshooting

Kafi baar network congestion ya SMS gateway delay ki wajah se GeM OTP phone par nahi aata:

- **Check Mobile DND Settings**: Agar aapke SIM par DND (Do Not Disturb) active hai, toh transactional SMS block ho sakte hain.
- **Use Email OTP Alternate**: GeM portal OTP registered Mobile aur Email ID dono par ek saath bhejta hai. Apna Email inbox / Spam folder check karein.
- **Browser Cache Clear**: Chrome browser ki cache aur cookies clear karke Incognito mode (Ctrl + Shift + N) mein try karein.

## 👤 Primary User vs Secondary User Login Differences

GeM portal par user accounts do types ke hote hain:

- **Primary User**: Organization ka main account admin (Proprietor, Director, Partner). Inke paas profile edit, Caution Money deposit, aur secondary user create karne ka full control hota hai.
- **Secondary User**: Employees ya bid managers jinhe Primary User dwara specific roles (Bid Creator, Bid Evaluator, Order Manager) assign kiye gaye hote hain.

> 💡 **Pro Tip**: Secondary User apna password reset karne ke liye apne Primary User admin se keh kar dashboard se direct password reset link trigger karva sakte hain.

## ❓ Frequently Asked Questions (FAQs)

### Q1: GeM portal par 3 baar galat password dalne se account lock ho gaya hai, ab kya karein?
GeM system security rule ke mutabiq 3 incorrect attempts par account 30 minutes ke liye temporarily lock ho jata hai. Aap 30 minutes wait kar sakte hain ya fir 'Forgot Password' link use karke turant password reset kar sakte hain.

### Q2: Purana Mobile Number aur Email band ho gaya hai, OTP kaise milega?
Agar aapka purana mobile aur email dono inactive hain, toh aapko official GeM Helpdesk portal par ticket raise karke official letterhead par Proprietor/Director authorization letter upload karna hoga.

### Q3: Key Manager / Primary User company chhod kar chala gaya hai, profile reset kaise karein?
New Director / Partner ko MCA21 / Udyam credentials ke saath GeM helpdesk par Primary User Transfer request file karni hogi.
