# GeM Primary User vs Secondary User: Roles, Permissions & User Transfer Guide

GeM portal par multi-user access feature businesses aur government departments dono ko efficiency deta hai. Lekin **Primary User aur Secondary User ke beech difference**, **permissions assignment**, aur **Primary User transfer** ko lekar kaafi confusion rehta hai.

Is guide mein hum detail mein samjhenge ki dono accounts ke kya rights hain aur employee change hone par account transfer kaise karein.

---

## ⚖️ Comparison Matrix: Primary User vs Secondary User

| Feature / Permission Scope | Primary User (Master Admin) | Secondary User (Delegate) |
|---|---|---|
| **Account Creation** | Self-registered via Aadhaar / PAN | Created by Primary User |
| **Profile & Company Edit** | ✅ Full Access (PAN/GST/Bank/Udyam) | ❌ Restricted |
| **Caution Money Deposit** | ✅ Full Access | ❌ Read Only |
| **Create Secondary Users** | ✅ Unlimited Allocation | ❌ No Access |
| **Bid Participation & Submission**| ✅ Full Access | ✅ Allowed (If Role Assigned) |
| **Catalogue & Product Listing** | ✅ Full Access | ✅ Allowed (If Role Assigned) |
| **Order Acceptance & Invoicing** | ✅ Full Access | ✅ Allowed (If Role Assigned) |

---

## 🛠️ How Primary User Can Create & Manage Secondary Users

1. Login with **Primary User Credentials**.
2. Go to **My Account** -> **User Management** -> Click **Add Secondary User**.
3. Enter Secondary User's Name, Official Email ID, Mobile Number, and Official Designation.
4. Select Roles & Division Permissions:
   - **Catalog Manager**: Product upload, price update.
   - **Bid Manager**: Tender search, technical bid compilation, price submission.
   - **Order Manager**: Order acceptance, shipment creation, invoice upload.
5. System bhejega activation link Secondary User ke email par to set password.

---

## 🔄 Step-by-Step Primary User Transfer Procedure

Jab kisi company ka Proprietor/Director badalta hai ya Key Manager job chhodta hai, toh Primary User Authority transfer karni padti hai:

1. **Active Primary User Login Available**: Primary User account mein login karein -> User Management -> **Transfer Primary User Role** -> Enter New Authorized User Aadhaar & Mobile -> Verify Dual OTP.
2. **Primary User Unavailable / Departed**: GeM Helpdesk portal par ticket raise karein. Official letterhead par **Board Resolution / Proprietorship Authorization Letter** upload karein along with New Primary User PAN & Aadhaar.

## ❓ Frequently Asked Questions (FAQs)

### Q1: Kya ek Secondary User ek se zyada role sambhal sakta hai?
Haan, Primary User ek hi Secondary User ko Catalog Manager, Bid Manager, aur Order Manager sabhi roles allocate kar sakta hai.

### Q2: Secondary User ki bidding activity ke liye kaun legally responsible hota hai?
Legal obligation aur contract liability hamesha Organization aur Primary User ke upar hoti hai.
