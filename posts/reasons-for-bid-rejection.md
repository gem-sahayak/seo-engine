## Top 7 Reasons For GeM Bid Rejection

GeM Buyers aur Scrutiny Committees dwara sabse zyada issue kiye jaane wale technical disqualification reasons:

```
1. Udyam NIC Code & Activity Mismatch
2. Invalid or Expired EMD / ePBG Instruments
3. Incomplete Experience & Past Performance Certificates
4. Generic OEM Authorization Letter Upload Issues
5. BOQ Compliance Specification Deviation
6. Invalid Financial Turnover Certificates (UDIN Missing)
7. Non-Compliance with Local Content (MII Class I/II) Criteria
```

---

## 1. Detailed Breakdown of Major Technical Rejection Causes

### A. Udyam NIC Code & Category Mismatch
Jab MSME seller EMD exemption claim karta hai, toh buyer scrutiny committee check karti hai ki supplier ke Udyam Registration Certificate par bid ke exact product/service ka **NIC 5-Digit Code** added hai ya nahi. Agar NIC code match nahi karta, toh bid instantly reject ho jati hai.

### B. EMD & Bid Securing Declaration Format Error
Agar seller EMD Deposit se exempt nahi hai, toh Bank Guarantee ya Demand Draft ki validity period bid requirement se kam hone par rejection hota hai. Exempt sellers ke case me formal **Bid Securing Declaration** sign karke PDF upload karna zaroori hai.

### C. Experience & Annual Turnover Documents Missing UDIN
CA dwara issued Chartered Accountant Financial Turnover certificates par official **UDIN (Unique Document Identification Number)** hona mandatory hai. Without UDIN certificates buyer committee cancel kar deti hai.

### D. Non-Compliant OEM Authorization (MAF)
Custom Goods tenders me Resellers ko original Manufacturer Authorization Form (MAF) upload karna padta hai. Generic authority letter ya specific Tender ID mention na hone par bid technical rejection ho jati hai.

## 2. Technical Evaluation vs Financial Disqualification Matrix

| Rejection Trigger | Scrutiny Stage | Can You Appeal (Representation)? | Preventive Compliance Action |
| :--- | :--- | :--- | :--- |
| **Udyam NIC Code Mismatch** | Technical Evaluation | YES (Within 48 Hours) | Bid upload se pehle Udyam profile update karein. |
| **EMD Validity Short** | Technical Evaluation | NO (Fatal Flaw) | EMD Instrument validity min 45 days beyond bid validity rakhein. |
| **BOQ Parameter Mismatch** | Technical Evaluation | YES (If Buyer Misunderstood Specs) | Signed Specification Compliance Sheet upload karein. |
| **High Financial Quote (L2/L3)** | Financial Opening | NO (Pure Pricing Order) | Commercial strategy review karein. |

## 3. How to File 48-Hour Technical Representation on GeM

GeM System rules ke mutabiq, jab Buyer Tender Evaluation status publish karta hai, tab rejected bidders ko system-generated **48 Hours** ka Representation Window milta hai.

### Step-by-Step Appeal Workflow:
1. Log in to GeM Seller Portal $\rightarrow$ Navigate to **My Bids** $\rightarrow$ Click **Technical Evaluation Status**.
2. Buyer dwara mention kiye gaye **Rejection Reason** ko carefully read karein.
3. Click on **Submit Representation** button.
4. Professional clarification draft karke, supporting proof PDFs (jaise Gazette notifications, CA certificates, or Manufacturer letters) attach karke submit karein.

Appeal letter formats aur drafting tips ke liye humara comprehensive guide [Writing Technical Representations for Disqualified GeM Bids](/knowledge/gem-bidding/representation-writing) zaroor padhein.

- [ ] Financial CA certificate par UDIN visible hai?
