# How to Search Bids on GeM Portal: Advanced Filters & Tender Search Guide 2026

Government e-Marketplace (GeM) portal par har din 50,000+ active tenders aur bids live hote hain. Lekin sahi bid dhoondhna MSME sellers ke liye sabse bada challenge hota hai kyunki standard search mein hazaron irrelevant tenders nikal aate hain.

Is practical 2026 guide mein hum dekhenge **GeM Advanced Bid Search techniques**, **Location & Ministry Filter tricks**, aur **BOQ / Custom Bid finding hacks**.

---

## 🔍 Understanding GeM Bid Search Structure

GeM portal par 4 main types ke procurement documents hote hain:

1. **Custom Bids**: Specific non-standard product/service requirements jinke liye buyers Custom Specification sheet upload karte hain.
2. **BOQ (Bill of Quantities) Bids**: Bulk item procurements jahan detailed BOQ excel sheet hoti hai.
3. **RA (Reverse Auctions)**: High-value bids jahan L1 determination real-time dynamic bidding se hota hai.
4. **Service Bids**: Manpower, Security, IT Outsourcing, Vehicle Hiring, Cleanliness Services.

---

## 🛠️ Step-by-Step Advanced Bid Search Strategy

### Step 1: Access GeM BidPlus Search Engine
GeM homepage (`gem.gov.in`) par **Bids** tab par click karein aur **Ongoing Bids / RAs** option select karein.

### Step 2: Use Quotation / Keyword Filters
Direct product name search karne ke bajaye HSN Code ya Category Taxonomy search karein. (Example: "Laptop" search karne ke bajaye "Desktop Computers" ya HSN Code `8471` search karein).

### Step 3: Apply Location & Department Filters
- **By State / City**: Active filters mein apna State (e.g., Madhya Pradesh, Uttar Pradesh, Maharashtra) aur Consignee Location select karein.
- **By Ministry / Department**: Defence, Railways, Health & Family Welfare, CPWD, BHEL filter apply karein.

### Step 4: Filter by Bid Value & EMD Exemption
MSMEs ke liye filter select karein: **MSE Exemption Allowed = Yes** aur **Startup Exemption Allowed = Yes**. Isse aapko wahi bids dikhenge jahan EMD ₹0 lagti hai.

## ❓ Frequently Asked Questions (FAQs)

### Q1: GeM par exact city ke tenders kaise dhoondhein?
Bid search page par Left Sidebar mein Consignee Location filter diya hota hai. City name enter karke filter apply karein.

### Q2: Bid Number se direct tender kaise kholte hain?
GeM BidPlus search bar mein exact Bid Number (e.g. `GEM/2026/B/1234567`) paste karke Enter dabayein.
