# GeM Catalogue Upload Process 2026: Golden Code Pairing & Rejection Fixes

Government e-Marketplace (GeM) portal par apne products aur services publish karna sabse critical step hai. GeM par Bina catalog upload kiye aap direct purchase, L1 comparison, ya bid participation nahi kar sakte.

Is 2026 step-by-step guide mein hum dekhenge **Product/Service Catalogue Upload Process**, **Golden Code parameters pairing**, **Brand Authorization (MAF)**, aur **Rejection Fixes**.

---

## 📦 Product vs Service Catalogue Upload Overview

| Aspect | Goods / Product Listing | Services Listing |
|---|---|---|
| **Taxonomy Structure** | Level 1 to Level 4 Category Path | Service Category + Scope Matrix |
| **Mandatory Identifiers** | HSN Code, Model Name, Golden Specs | SAC Code, Experience Criteria |
| **Approval Authority** | Auto-Approval / GeM Category Admin | GeM Service Admin Approval |
| **Brand Linkage** | OEM Brand / Registered Brand / Unbranded | Service Provider Designation |

---

## 🛠️ Step-by-Step Catalogue Listing Process

### Step 1: Select Correct Category Taxonomy
Catalog Manager dashboard par **Add New Product** click karein. Category search bar mein product name enter karke L1->L2->L3->L4 exact category path select karein.

### Step 2: Brand & Model Selection
- **Registered OEM Brand**: Select existing brand from dropdown. (Requires OEM Authorization Code / MAF Number).
- **Unbranded / Custom**: Select 'Unbranded' option if listing generic items (Subject to price ceiling limits).

### Step 3: Golden Code Specification Pairing
GeM categories mein mandatory **Golden Parameters** (indicated with golden star icon) hote hain e.g. Processor Type, RAM, Sheet Thickness, Material Grade. Ensure karein ki aapke product test report aur catalogue specs Golden Parameters se 100% match karein.

### Step 4: Pricing & MRP Declaration
- Enter Maximum Retail Price (MRP).
- Enter **GeM Selling Price** (Must be at least 1% to 10% lower than MRP as per GeM policy).
- Select Quantity Slabs for Volume Discounts.

---

## 🚨 Top 3 Catalog Rejection Reasons & Solutions

1. **MRP Proof Missing**: Product MRP box, catalog page, ya OEM price list declaration upload na karne par rejection hota hai. Clean image upload karein.
2. **Golden Parameter Mismatch**: Selected parameters product image/spec sheet se match na karne par admin reject kar deta hai.
3. **Invalid Brand Authorization Letter**: Resellers ko OEM Manufacturer Authorization Form (MAF) upload karna zaroori hai.

## ❓ Frequently Asked Questions (FAQs)

### Q1: Product upload hone ke kitne time baad GeM portal par live hota hai?
Standard OEM/Brand items 5–10 minutes mein auto-publish ho jate hain. Non-brand ya new category items administrative review ke liye 24–48 hours lete hain.

### Q2: Kya hum published catalogue ka price kabhi bhi change kar sakte hain?
Haan, dashboard se Manage Products mein jaakar aap price update kar sakte hain, lekin ongoing bid or active contract orders par old price hi apply hoga.
